Memory guide

RAM capacity and slot checklist

Before choosing a kit, understand what is installed and what can actually be replaced.

Count modules and slots

A 16 GB system may contain one 16 GB module or two 8 GB modules, creating different upgrade paths.

Check soldered memory

Windows can report capacity without proving that every memory bank is user-replaceable. Hardware documentation is needed when soldered memory is involved.

Diagnose the bottleneck first

If the PC is not under meaningful memory pressure, adding RAM may not fix the symptom that prompted the upgrade.
