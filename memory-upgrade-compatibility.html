Memory guide

Memory upgrades need platform matching

More gigabytes help only when the modules are the correct type for the system.

Match DDR generation

DDR4 and DDR5 are different standards and are not interchangeable. The motherboard and processor platform determine support.

Match the form factor

Desktops commonly use DIMMs and laptops commonly use SO-DIMMs. Some thin laptops have soldered memory and no user-replaceable slots.

Respect capacity limits

Maximum supported memory depends on the platform, firmware and slot configuration. Confirm the documented limit before buying a large kit.
