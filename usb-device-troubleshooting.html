Troubleshoot a USB device before replacing it

A failed device, failed port and Windows enumeration problem can look similar.

Change one variable at a time

Try a known-good port, then another computer if possible. Avoid changing ports, hubs, drivers and cables simultaneously.

Remove hubs from the test

Connect directly when possible because marginal cables or unpowered hubs can cause intermittent disconnects.

Check Windows device state

If Windows reports a device problem code, investigate that before buying replacement hardware. A Plug and Play rescan is a conservative first step.
