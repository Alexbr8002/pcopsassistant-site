Keyboard guide

Use an external keyboard as a diagnostic boundary

A second keyboard is both a workaround and a controlled comparison.

Choose a simple test device

A basic Windows-compatible USB keyboard is ideal because it avoids Bluetooth pairing and battery variables.

Repeat the exact same test

Use the same Windows session, application and suspect keys. A clean external result while the internal keyboard still fails is meaningful evidence.

If both keyboards fail

Do not buy a replacement yet. Check layout, accessibility settings, remapping utilities, remote-control software and device errors.

If the external keyboard works

Use it temporarily while deciding whether internal keyboard service is worth the cost and installation complexity.
