Privacy Policy

PCOps Assistant · Last updated September 14, 2026

Summary

The core PCOps Assistant diagnostic workflow runs locally on your Windows PC. PCOps does not require an account, telemetry or analytics for normal diagnostic use.

What PCOps reads

  • Operating system, hardware, memory and storage inventory.
  • Installed software and Windows Update status.
  • Driver inventory and update readiness.
  • Startup entries and Windows Event Log health signals.
  • Storage-device identity needed to correlate drive-health data across scans.

PCOps does not need to read the contents of personal documents, browsing history, passwords, Windows product keys or license keys belonging to other software during normal diagnostics. If you choose to activate PCOps Full, PCOps processes the Full license key you enter.

What PCOps stores

Saved diagnostic history is stored locally at %LOCALAPPDATA%\PCOpsAssistant\pcops.db. The file remains on the PC after uninstall so history can be preserved for a later reinstall. You may delete it manually if you want to remove saved history.

Network use

The core diagnostic workflow does not require PCOps telemetry or a PCOps cloud service. Optional update-related actions may invoke Windows or WinGet services. Those external Windows services can access the network when you explicitly request an update action. PCOps Full licensing, when production licensing is enabled, contacts the licensing provider over HTTPS only for user-initiated activation, validation or deactivation; diagnostic and hardware data are not sent with those licensing requests.

Support data

If you contact support, information you choose to send by email is used only to investigate and respond to your request. Do not send passwords, product keys or unrelated personal files.
