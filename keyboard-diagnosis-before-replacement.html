Keyboard guide

Diagnose before replacing a keyboard

A missed key in one test is evidence, not a hardware verdict.

Confirm what Windows receives

Test the expected keys in a controlled window and record only which key identities arrive. A typo, focus loss or incomplete pass should not be treated as hardware failure.

Repeat the same suspect keys

Repeatability matters. If the same keys fail again while nearby keys work normally, the pattern is stronger than a single missed input.

Check Windows device state

A device problem code or unhealthy state changes the next step: resolve that Windows or driver issue before assuming the physical keyboard needs replacement.

Compare with an external keyboard

If the external keyboard works normally while the same internal keys continue to fail, the original keyboard or its physical connection becomes the likely boundary.
